## What to look for

- **Obsidian callouts**: `[!abstract]`, `[!success]`, `[!warning]`, `[!info]`, `[!example]`, `[!danger]`, `[!tip]`
- **LaTeX rendering**: block `$$...$$` and inline `$...$` formulas
- **`[[wiki-links]]`**: bidirectional links between papers and concepts
- **Structured frontmatter**: Dataview-queryable YAML metadata
- **Emoji section headers**: consistent visual anchors (📋 📊 🎯 🔬 💡 ⚠️)
